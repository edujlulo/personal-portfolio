Veterinary Clinic Management System

  • Production-oriented veterinary clinic management system built with React, TypeScript, Tailwind CSS and Supabase.
  • Feature-based architecture designed for scalability, maintainability and real-world business requirements.
  • Manages relational data (owners, pets and visits) with structured medical history and vaccination tracking.
  • Implements clean state management, reusable components and type-safe patterns.
  • Designed as a real application for an actual clinic — not a simple CRUD demo.
